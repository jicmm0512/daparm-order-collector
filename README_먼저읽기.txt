다팜몰 카카오톡 알림수집 v0.4 - Android Studio 소스코드 테스트판

중요: APK 파일이 아닙니다. 휴대폰에 바로 설치할 수 없습니다.
Windows PC에 Android Studio를 설치한 뒤 프로젝트 폴더를 열고 Gradle Sync 후 APK를 빌드해야 합니다.

[작동 방법]
1. Android Studio에서 프로젝트를 엽니다.
2. Build > Build APK(s)로 테스트 APK를 생성합니다.
3. 본인이 소유한 갤럭시 휴대폰에 설치합니다.
4. 앱을 열고 다팜몰 오픈채팅방 이름을 정확하게 입력하고 저장합니다.
5. '알림 접근 권한 설정 열기'에서 이 앱에 대한 접근을 직접 허용합니다.
6. 카카오톡을 닫거나 다른 화면으로 이동한 상태에서 테스트 계정으로 해당 방에 메시지를 보냅니다.
7. 수집 내역을 새로고침해 확인합니다.

[제한 및 주의]
- 공식 카카오톡 오픈채팅 읽기 API가 아닙니다. 안드로이드 알림 접근 기능을 사용합니다.
- 카카오톡 알림이 안 뜨거나 내용이 숨겨지면 수집되지 않습니다.
- 카카오톡 알림의 대화방 이름이 정확히 제공되지 않으면 개인정보 보호를 위해 저장하지 않습니다.
- 알림 묶음/재게시/휴대폰과 PC 동시 사용에 따른 누락 및 중복이 발생할 수 있습니다.
- 이 버전은 서버 통신이 없고, v0.3 장부에 자동으로 합산하지 않습니다.
- 메시지 내용은 휴대폰 내부 앱 전용 저장소에 저장되며 외부 전송하지 않습니다.
- CSV/JSON 공유를 실행하면 사용자가 선택한 다른 앱으로 데이터가 전달될 수 있습니다.
- 회원들에게 주문 메시지 수집 목적과 보관 기준을 사전에 안내하세요.
- 실제 운영 전 카카오톡 및 안드로이드 이용조건을 확인하세요.
- 이 소스는 실제 기기에서 컴파일/실행 검증하지 못했습니다. 필요 시 빌드 오류를 수정해야 합니다.
